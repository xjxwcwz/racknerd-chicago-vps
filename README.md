## 三网回程都走美西中转，220ms 是这条路线的下限

国内三网连芝加哥，物理距离绕不开。中文测评给出的口径是去程基本都从美西进：电信走圣何塞，联通走洛杉矶双向，移动出口圣何塞、回程洛杉矶或西雅图。英文侧的路径记录更细一些：

- **电信**：回程经 Ashburn 和 San Jose 再跨太平洋
- **联通**：回程经 San Jose
- **移动**：走 CMI

三条都是普通线路。CN2 和 AS9929 这类精品线路在芝加哥机房没有，所以延迟比圣何塞、洛杉矶 DC-02 高出一截。综合两个来源，到中国大陆大概在 200–230ms，中文测评的实测口径是 220ms 上下，和常见美东机房持平。

对比一下 RackNerd 自家其他位置：洛杉矶和圣何塞 150–180ms。中间差 50–70ms，网页首屏能感觉到，SSH 敲命令也能感觉到。

**哪些人该直接跳过芝加哥：**

- 主要访客在中国大陆的站点，尤其是电商、内容站这类对首屏敏感的类型
- 把美国 VPS 当日常代理或流媒体中转、只在乎 ping 值的人
- 需要频繁从国内传大文件上来的工作流

有测评提到国内南方电信某些区域上传会掉到 50Mbps 左右，这属于国内回程带宽的问题，换哪家美国机房都差不多，不能算在芝加哥头上。

反过来说，芝加哥到美东和欧洲的延迟是它的本钱。机房位置选在 Elk Grove Village，离芝加哥市区的金融交易所有段距离但同属一个都市圈，RackNerd 的 CEO Dustin B. Cisneros 在 2020 年 9 月 21 日的开业新闻稿里说过，芝加哥的市场需求一直由连通性和靠近金融交易所这两点驱动。这话放到今天依然成立。

## 硬件、磁盘和那个美国原生 IP

芝加哥机房的主流配置是 Intel Xeon E5-2690 v2，3.0GHz 主频，磁盘走 RAID-10 SSD。有第三方测评作者自述，他跑了大约 8 个月的 2GB 特惠，SSD 读写稳定在 700MB/s 以上，1Gbps 端口在非高峰时段到美国对端能接近线速；中文测评给的磁盘数字是 791MB/s 上下，下载到国内外节点基本都在 600Mbps 以上，上传到欧洲节点表现更好。这些是测评作者自己的测试结果，不是官方标称，参考着看。

内存方面，中文测评提到 1GB 机型会附带 1.5GB 虚拟内存，表述比较含糊，可能指 swap，别把它当成实际可用内存来规划。

IP 是芝加哥机房真正的卖点。分配的地址段在 198.23.x，属于美国原生 IP。中文测评实测 TikTok、Netflix、HBO、YouTube 几个主流美区平台都能正常解锁，IP 会被识别为数据中心 IP，但不影响流媒体播放。英文测评的说法是这批 IP 没有被标记成"数据中心代理重灾区"，不像某些洛杉矶 IP 段那样容易被风控拦。用中国移动宽带通过它看 YouTube，中文测评的实测速度稳定在 60000+，4K 不卡，比美西常见的 100000+ 低一些。

**25 端口默认开放。** 想做轻量邮件服务、自建邮局，开箱就能用，不用单独提工单申请解封。这一条在便宜 VPS 里不算常见，很多人买之前不会想到问。
